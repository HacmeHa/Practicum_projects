# АНАЛИЗ БИЗНЕС-ПОКАЗАТЕЛЕЙ РАЗВЛЕКАТЕЛЬНОГО ПРИЛОЖЕНИЯ PROCRASTINATE PRO+

ЦЕЛЬ И ПЛАН ИССЛЕДОВАНИЯ
------------------------
Цель: определить откуда приходят пользователи и какими устройствами они пользуются,
сколько стоит привлечение пользователей из различных рекламных каналов,
сколько денег приносит каждый клиент,
когда расходы на привлечение клиента окупаются,
какие факторы мешают привлечению клиентов.

План: 
+ Знакомство с данными
+ Предобработка данных
+ Установление функций для расчёта и анализа
+ Исследовательский анализ данных
+ Маркетинг
+ Определение окупаемости рекламы
+ Общие выводы и рекомендации рекламному отделу.

ВЫВОД
-----------------
Рекомендации для рекламного отдела.

Рекламному каналу TipTop уменьшить бюджет в Америке для «яблочных» устройств, т.к. пользователей из этой страны большинство, а через эти устройства приходит итак много пользователей.
В канал FaceBoom повышать вложение бюджета пока не стоит. Пользователи благодаря этому каналу хорошо покупают, но плохо удерживаются. Возможно, этот канал привлекает клиентов, которые не полностью заинтересованы в продукте или услуге. Например, если это реклама со скидками, то клиент может купить что-то только ради экономии.
Вложиться в рекламный канал YRabbit – он показал лучшую рентабельность. Лучшей она была за счет большого скачка окупаемости в июле (проверить что произошло в июле, возможно была акция). Распространить на другие каналы или повторить у канала YRabbit.
